# px-to-rem

Конвертер px в rem на чистом JavaScript.

## Что делает

Принимает размер в пикселях и показывает его в rem. Базовый размер шрифта: 16 px, поэтому 24 px = 1.5 rem.

## Как запустить

1. Скачай репозиторий или открой сайт: https://halimaaltyn2026.github.io/px-to-rem/
2. Если скачала файлы, открой `index.html` в браузере
3. Введи число и нажми «Перевести»

## Что проверено

- Пустое поле: сообщение «Введите число.»
- Текст вместо числа (`abc`): сообщение «Это не число. Пример: 24»
- Отрицательное число: сообщение «Число не может быть отрицательным.»
- Запятая вместо точки (`1,5`) работает

## Какие темы CSS использованы

- CSS-переменные (`:root`, `var()`) для цветов
- Тёмная тема через `prefers-color-scheme`
- Единицы `rem` и функция `clamp()` для размера заголовка
- Grid-раскладка и адаптив через `@media (min-width: 40rem)`
- Состояния `:hover` и `:focus-visible`
- Плавные переходы (`transition`) и уважение к `prefers-reduced-motion`
